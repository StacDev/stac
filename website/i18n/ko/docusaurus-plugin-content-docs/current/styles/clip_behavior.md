# Clip

`clipBehavior` 속성은 박스 외부의 콘텐츠를 처리하는 방법을 결정합니다:

| 값                       | 설명                                                            |
| ------------------------ | --------------------------------------------------------------- |
| `none`                   | 클리핑이 적용되지 않습니다 (기본값).                             |
| `hardEdge`               | 안티앨리어싱 없이 콘텐츠를 클리핑합니다.                          |
| `antiAlias`              | 더 부드러운 가장자리를 위해 안티앨리어싱을 사용하여 콘텐츠를 클리핑합니다. |
| `antiAliasWithSaveLayer` | 안티앨리어싱을 사용하여 콘텐츠를 클리핑하고 페인팅을 위한 오프스크린 버퍼를 저장합니다. |

## 예제 JSON

```json
{
  "type": "fittedBox",
  "clipBehavior": "hardEdge"
}
```
