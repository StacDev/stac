# Get Form Value Action

`StacGetFormValueAction` 클래스는 Stac 애플리케이션에서 폼 값을 가져오는 데 사용됩니다.

## 속성

| Property  | Type     | Description                        |
|-----------|----------|------------------------------------|
| id        | `String` | 가져올 폼 필드의 ID.   |

## 예제 JSON

### Get Form Value Action JSON

```json
{
  "actionType": "getFormValue",
  "id": "username"
}
```
