# SizedBox

Stac sizedBox를 사용하면 JSON을 사용하여 Flutter sizedBox 위젯을 빌드할 수 있습니다.
Flutter의 sizedBox 위젯에 대해 자세히 알아보려면 [공식 문서](https://api.flutter.dev/flutter/widgets/SizedBox-class.html)를 참조하세요.

## 속성

| Property | Type                    | Description                          |
|----------|-------------------------|--------------------------------------|
| width    | `double?`               | SizedBox의 너비            |
| height   | `double?`               | SizedBox의 높이           |
| child    | `Map<String, dynamic>?` | SizedBox 내부의 자식 위젯 |

## 예제 JSON

```json
{
  "type": "sizedBox",
  "height": 25
}
```
