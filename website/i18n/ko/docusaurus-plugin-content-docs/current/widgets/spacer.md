# Spacer

Stac Spacer를 사용하면 JSON을 사용하여 Flutter spacer 위젯을 빌드할 수 있습니다.
Flutter의 spacer 위젯에 대해 자세히 알아보려면 [공식 문서](https://api.flutter.dev/flutter/widgets/Spacer-class.html)를 참조하세요.

## Properties

| Property | Type  | Description                                             |
|----------|-------|---------------------------------------------------------|
| flex     | `int` | spacer에 사용할 flex 팩터입니다. 기본값은 `1`입니다. |

## Example JSON

```json
{
  "type": "spacer",
  "flex": 2
}
```
