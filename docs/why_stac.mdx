## 1. What is Stac?

**Stac** is a **Server-Driven UI (SDUI) framework for Flutter** that allows you to build, update, and deliver dynamic user interfaces without redeploying your app.
Instead of hard-coding every widget in Flutter, you define your UI as **Stac Widgets** that render at runtime from JSON.

## 2. Why it matters

- **Instant updates** — Ship UI changes without waiting for app store reviews.  
- **Independent releases** — Product teams can update UI while engineers focus on logic and performance.  
- **Faster iteration** — A/B test layouts, experiment with flows, and personalize experiences on the fly.  
- **One definition, all platforms** — Deliver consistent UI across iOS, Android, web, and desktop.  
- **Team empowerment** — Let designers and PMs control presentation directly from the cloud.  
- **Centralized safety** — Keep UI logic on the server to reduce client-side inconsistencies and errors.

## 3. What is Server-Driven UI?

Server-Driven UI (SDUI) shifts the presentation layer from the client to the server.  
Instead of shipping static layouts in your app, the UI is described in JSON and rendered dynamically at runtime.

1. The server sends a JSON schema defining structure, content, and actions.  
2. The client interprets that JSON into native Flutter widgets.  
3. Any server change instantly updates the app UI—no redeploy needed.

This approach makes your app flexible, lightweight, and easy to evolve.

## 4. What makes Stac powerful

- **90+ Built-in Widgets** — Pre-configured Material components for layouts, input, navigation, and more.  
- **11+ Action Handlers** — Handle navigation, dialogs, API calls, forms, and advanced multi-actions.  
- **Full Theming Support** — JSON-driven `ThemeData` with Material 3, dark mode, and granular overrides.  
- **Custom Parsers** — Extend Stac with your own widgets and actions tailored to your domain.  
- **Dynamic Logic** — Use runtime variables, expressions, and conditions to adapt the UI.  
- **Form Engine** — Built-in form handling, validation, and state management.  
- **Error Handling** — Customizable error widgets, safe fallbacks, and integrated logging.  
- **Cross-Platform** — Runs seamlessly on mobile, web, desktop, and WASM.

## 5. The advantages of SDUI

- **Faster delivery** — Roll out UI updates in minutes, not weeks.  
- **Unified experience** — Maintain visual and behavioral consistency across platforms.  
- **Personalized UX** — Adapt screens dynamically per user or experiment group.  
- **Safe experimentation** — Test new features server-side without client updates.  
- **Scalable design ops** — Manage and coordinate UI changes centrally as your app grows.  
- **Improved security** — Keep sensitive presentation logic off the client.
