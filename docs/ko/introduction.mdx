# Stac란?

**Stac**은 **Flutter를 위한 서버 기반 UI(Server-Driven UI, SDUI) 프레임워크**로, 앱을 다시 배포하지 않고도 동적인 사용자 인터페이스를 구축하고 업데이트할 수 있게 해줍니다.
모든 위젯을 코드로 고정하는 대신, 런타임에 JSON으로 렌더링되는 **Stac 위젯**을 정의합니다.

이 방식은 표현 계층과 비즈니스 로직을 분리하여 다음을 가능하게 합니다.

- **즉시 업데이트 배포.** Stac 위젯을 수정해 Stac Cloud에 푸시하면 됩니다.
- **기능 실험**(A/B 테스트, 개인화 등)을 새 릴리스 없이 진행.
- 단일 스키마로 여러 플랫폼에서 **일관된 UI 유지**.
- 디자이너, PM 등 **비개발자도 레이아웃과 콘텐츠를 제어**.
