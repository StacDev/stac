---
title: "VerticalDivider"
description: "세로 구분선"
---

| 속성 | 타입 | 설명 |
|------|------|------|
| width | `double?` | 전체 폭 |
| thickness | `double?` | 선 두께 |
| indent / endIndent | `double?` | 위/아래 간격 |
| color | `String?` | 선 색상 |

## 예제

```json
{
  "type": "verticalDivider",
  "width": 20,
  "thickness": 4,
  "indent": 10,
  "endIndent": 10,
  "color": "#21814C"
}
```
