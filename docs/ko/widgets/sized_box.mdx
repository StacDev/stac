---
title: "SizedBox"
description: "고정 크기 또는 빈 공간 생성"
---

`sizedBox`는 고정된 너비/높이를 갖는 상자를 만들거나 단순히 공간을 채우는 용도로 사용합니다.

## 속성

| 속성 | 타입 | 설명 |
|------|------|------|
| width | `double?` | 상자 너비 |
| height | `double?` | 상자 높이 |
| child | `Map<String,dynamic>?` | 들어갈 자식(없으면 빈 공간) |

## 예제

```json
{
  "type": "sizedBox",
  "height": 25
}
```
