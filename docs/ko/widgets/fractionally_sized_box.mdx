---
title: "FractionallySizedBox"
description: "부모의 비율만큼 공간 차지"
---

`fractionallySizedBox`는 부모 크기의 일부만 사용하도록 설정합니다.

## 속성

| 속성 | 타입 | 설명 |
|------|------|------|
| alignment | `StacAlignment?` | 자식 정렬 |
| widthFactor | `double?` | 부모 너비 대비 비율 |
| heightFactor | `double?` | 부모 높이 대비 비율 |
| child | `Map<String,dynamic>?` | 내부 자식 |

## 예제

```json
{
  "type": "fractionallySizedBox",
  "alignment": "center",
  "widthFactor": 0.5,
  "heightFactor": 0.5,
  "child": {
    "type": "container",
    "color": "#FF5733",
    "child": {
      "type": "text",
      "data": "Hello, World!"
    }
  }
}
```
